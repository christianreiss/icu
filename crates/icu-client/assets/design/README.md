# ICU design reference icons

These SVG paths are taken directly from the operator-supplied ICU Desktop Redesign
reference: https://claude.ai/artifact/VnjxAgCZ8karjkq4MfUdbR#page-dcb81aee8d83

Only the SVG namespace and a white base stroke (tinted at runtime) were normalized.
Geometry, view boxes and stroke widths are preserved. Assets are local; the client
does not load fonts, scripts or images from the reference website.
